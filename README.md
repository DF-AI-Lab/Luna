# Luna 🌙

Darren's morning briefing agent.

Every morning before 8am (UK) Luna checks TaskNotes, Calendar and Gmail, then shows one **card page**:
one card per thing, with a reply box on each.

- Main rules: `BRIEFING.md`
- Helper rules: `helpers/`
- Already dealt with: `known-facts.md`
- Card replies (training data for Orbit): `log/`
- Project file (start here): `luna.md`
- Live page: `app/luna.html` (published at https://claude.ai/artifact/K9WPKsdLQLMoMyb6iCPm5C)
