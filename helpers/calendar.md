# Calendar helper

## Memory
- Read `helpers/calendar-memory.md` first. Report only what is NEW or CHANGED since then; say "nothing new" otherwise.
- At the end, hand back your updated memory (max 30 lines) for Opus to save.
- Checking is read only. Only change things when Opus sends you to act on Darren's reply.


## Look
- Events today and in the next 7 days
- Clashes (two things at the same time)

## Bring back (short list, one line each)
- Event name, day, time, place, and any clash

## When told to add
- Add the event. If no time is known, add it as an all-day event and say "time to confirm" in the title.
- Hand back the event id. Never delete or move events unless Opus says Darren asked.
